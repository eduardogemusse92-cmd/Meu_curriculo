# Meu Currículo — Eduardo Gemusse

Projeto prático de Programação de Design Web, construído com HTML5 e CSS3 puro, sem JavaScript e sem frameworks.

## Páginas
- `index.html` — apresentação pessoal.
- `about.html` — currículo, formação, competências e tabela.
- `portfolio.html` — projetos em grelha.
- `hobbies.html` — hobbies com Flexbox e multimédia.
- `contact.html` — formulário com validação nativa HTML5.

## CSS
- `css/estilo.css` — estilos partilhados, variáveis, seletores, Flexbox/Grid, pseudo-classes, pseudo-elementos, transições e animação.
- `css/responsivo.css` — media queries para telemóvel, tablet e desktop.

## Multimédia
As imagens locais de demonstração estão em `assets/img/` e existe um áudio local em `assets/audio/apresentacao.wav`.
Substitua o ficheiro `assets/video/apresentacao.mp4` pelo seu vídeo real de apresentação antes da entrega.

## Como visualizar
Abra `index.html` num navegador. Para publicar, mantenha a estrutura de pastas e envie o projeto para um repositório público no GitHub.

## Observação
Os textos, nome e dados devem ser revistos pelo estudante antes da entrega para garantir que correspondem aos seus dados reais.
